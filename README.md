- [edgecache](https://github.com/crowbett/edgecache): RFC 9111 HTTP caching reverse proxy
- [kvlite](https://github.com/crowbett/kvlite): embedded bitcask-style key-value store
- [codegraph](https://github.com/crowbett/codegraph): tree-sitter symbol and call graph served over MCP (Rust)
